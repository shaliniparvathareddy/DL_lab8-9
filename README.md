# Flower Classification Using ResNet50 and Attention

## Aim
To classify flower images using a pretrained ResNet50 model and study how attention mechanisms affect the results.

## Dataset
The experiment uses a flower image dataset containing five classes.

## Models Used
- ResNet50 Baseline
- ResNet50 with Attention

## Requirements
Python and the libraries listed in `requirements.txt`.

## How to Run
1. Install the required libraries.
2. Keep the dataset in the correct folder.
3. Run the experiment Python file.
4. Check the printed results and generated plots.

## Output
The experiment generates accuracy and loss graphs, model comparison plots, confusion matrices, feature maps, attention maps, and Grad-CAM visualizations.

## Conclusion
This experiment helps us understand how attention can change the features learned by ResNet50 and affect flower classification performance.
